## **🎮 Featured Project: Shadow Jumper**  
**Shadow Jumper** is a **2D vertical platformer game** built using **HTML5 Canvas** and vanilla **JavaScript**.  

### **🚀 Key Features**  
✔ **Smooth physics-based movement** (gravity, jumping)  
✔ **Procedurally generated platforms** for endless climbing  
✔ **Dynamic difficulty** (enemy speed scales with progress)  
✔ **High-score tracking** using `localStorage`  
✔ **Retro-style graphics** and immersive soundtrack  
✔ **Quick restart** with player credits
